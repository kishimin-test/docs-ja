## 解決したい課題

プロフィール・経歴・スキル・SNSリンク・お知らせを管理する画面がなく、公開サイトの about ページに表示する内容を管理者が更新できない。これらを更新するために DB を直接操作する運用は現実的でない。

## 提案する解決策

プロフィール系リソースの管理画面を実装する。

### 画面

| パス | 内容 |
| ---- | ---- |
| `/profile` | プロフィール、経歴、スキル、SNSリンクの編集 |
| `/settings` | お知らせの管理とサイト設定 |

### 機能

- **プロフィール** — 名前、肩書き、紹介文の編集
- **経歴** — 追加・編集・削除・並び替え
- **スキル** — 追加・編集・削除・並び替え。カテゴリと習熟度を含む
- **SNSリンク** — 追加・編集・削除・並び替え。URL 形式の検証
- **お知らせ** — 作成・編集・削除・公開/非公開の切り替え

### 振る舞い

- 並び替えの結果が公開サイトの表示順に反映される
- 削除時に確認ダイアログを表示する
- 日英両方の内容を編集できる
- API の検証エラーを該当フィールドへ表示する
- 未保存の変更がある状態で画面を離れようとしたときに警告する
- 並び替えがキーボードのみでも操作できる

## 代替案

- **リソースごとに独立したページに分ける** — 画面数は増えるが構造は単純になる。about ページに載る情報がまとまっているため、まず 1 画面に集約し、項目が増えた時点で分割を検討する。

## 受入条件

- [ ] プロフィールを編集して保存すると公開サイトの about ページに反映される
- [ ] 経歴・スキル・SNSリンクを追加・編集・削除できる
- [ ] 並び替えた順序が保存され、公開サイトの表示順に反映される
- [ ] 並び替えがキーボードのみで操作できる
- [ ] 削除時に確認ダイアログが表示され、キャンセルすると削除されない
- [ ] 不正な URL の SNS リンクを保存しようとするとエラーが表示される
- [ ] お知らせを作成し、公開 / 非公開を切り替えられる
- [ ] 非公開のお知らせが公開サイトに表示されない
- [ ] 日本語と英語の内容を編集して保存できる

## 対象外

- アバター画像のアップロード — v2 (当面は URL 指定)
- 管理者アカウント自身の設定変更 (パスワード変更など)

## 補足
