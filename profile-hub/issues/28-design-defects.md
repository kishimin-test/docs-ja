## 解決したい課題

8 つのアートボードを PNG に書き出して確認したところ、デザイン自体にすでに現れている不具合が見つかった。この状態のファイルから実装すると、不具合をそのまま再現するか、実装者が独自に補正することになる。

### コンポーネントがコンテナからはみ出している

Input コンポーネント `EL-6ce18297` は幅 **520px 固定**で、それより狭いコンテナで再利用されている。

| 画面 | コンテナ内幅 | Input 幅 | 超過 | 描画結果 |
| ---- | ------------ | -------- | ---- | -------- |
| `Admin / Login` `#3:9`, `#3:13` | 350px (カード430 − padding80) | 520px | **+170px** | メール・パスワード欄がカード右端で切れている |
| `Admin / Editor` `#3:130`, `#3:134` | 254px | 520px | **+266px** | `ステータス` 欄が切れている |
| `Admin / Editor` `#3:121`, `#3:125`, `#3:142` | 520px | 520px | 0 | 正常 |

ログイン画面は v1 の必須画面で、入力欄がカードから溢れたままになっている。同じカード内の「ログイン」ボタン (`#3:15`) は 350px で正しいため、Input だけが可変幅化されていない。

### 複数行入力の文字が上下中央揃えになっている

`本文（Markdown）` 欄 (`#3:138`) が単行 Input の `alignItems: center` をそのまま引き継いでいるため、Markdown テキストが 285px の枠の縦中央に描画され、上に約 110px の空白ができている。複数行入力は上揃えにする必要がある。

### フッターのリンクが描画されていない

public の 5 アートボードすべてで、フッターに著作権表記しか表示されない。`GitHub   X   Contact` ノード (`#2:49`, `#2:102`, `#2:150`, `#2:187`, `#2:220`) が現れず、`justifyContent: space-between` から期待される 64px の左端ではなく、著作権表記が水平中央付近に描画されている。ノードが非表示か、フレーム外に配置されている可能性がある。

著作権表記も `©kishimin2026` とスペース無しで、既存ドキュメントの `© kishimin 2026` と一致しない。

### その他のレイアウト不具合

| ID | 画面 | 内容 |
| -- | ---- | ---- |
| V-4 | Home | お知らせバナー (`#2:44`) がページフレーム直下にあり横 padding が無いため x=0 から描画される。他はすべて x=64 から始まるので、左に 64px はみ出し右に 128px の空きができている |
| V-5 | About | フレーム高さ 1370px に対し Skills タグが下端に描画され、フッター (`#2:100`) が画面外へ押し出されている |
| V-6 | Engineering Article | 空のテキストノード (`#2:176`) がキーワード見出しとタグの間に約 125px の不自然な空白を作っている |
| V-7 | Admin Articles | 一覧カード (`#3:57`) が 480px 固定で、4 行の下に約 128px の空白が残る |
| V-8 | Admin Editor | フレーム高さ 1080px に対しサイドバー (`#3:87`) が 900px 固定で、濃色が途中で途切れ背景が見えている |
| V-9 | Admin Editor | 公開設定パネル (`#3:144`) が 410×620 固定だが内容は約 200px 分しかない |
| M-5 | Home | 記事カードが 1098px (350×3 + 24×2) で、コンテンツ幅 1152px に対し 54px 余る。368px にすればちょうど収まる |

## 提案する解決策

Figma ファイル上でそれぞれを修正する。

- `EL-6ce18297` を固定幅ではなく親幅に追従させる
- 複数行の本文欄を上揃えにし、単行 Input とは別コンポーネントに分ける
- フッターのリンクを復元する、または著作権表記のみが意図であることを確認して記録する
- お知らせバナーにページと同じ横インセットを与える
- About のフレーム高さを内容に合わせて広げ、フッターが見えるようにする
- 記事ページの空テキストノードを削除する
- Admin の一覧カードとサイドバーを内容に応じて可変にする
- 公開設定パネルを記事管理Issue (#14) と併せて設計し直す
- Home の記事カード幅をコンテンツ幅に合わせる

## 代替案

- **不具合を残して実装時に補正する** — 実装者ごとに解釈が分かれ、Figma ファイルが参照先として信頼できなくなる。不採用。

## 受入条件

- [ ] どのアートボードでも Input がコンテナ外に描画されない
- [ ] Markdown 本文欄が枠の上端から文字を描画する
- [ ] public の 5 アートボードすべてでフッターが意図した内容を一貫して描画する
- [ ] お知らせバナーがページ内容と同じ左右端になる
- [ ] About アートボードでフッターが見える
- [ ] 記事ページのキーワード見出しとタグの間に不自然な空白が無い
- [ ] Admin の一覧カードが 4 行時に大きな空白を持たない
- [ ] Admin のサイドバーが各アートボードの下端まで届く
- [ ] Home の記事カードがコンテンツ幅を満たす
- [ ] 著作権表記がドキュメントの表記と一致する
