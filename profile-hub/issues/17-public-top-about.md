## 解決したい課題

profile-hub は自己紹介サイトだが、訪問者が「この人が誰で、何をしている人か」を知るページがない。トップページと about ページは、訪問者が最初に到達し、他のページへ回遊する起点になる。

## 提案する解決策

トップページ (`/`) と about ページ (`/about`) を実装する。

### トップページ (`/`)

- 名前、肩書き、短い紹介
- 趣味記事・技術記事への導線
- 最新記事の抜粋 (数件)
- お知らせがある場合の表示
- SNSリンク

### about ページ (`/about`)

- プロフィール (名前、肩書き、紹介文)
- 経歴 — 管理画面で指定した順序で表示
- スキル — カテゴリごとにまとめ、習熟度を表示
- SNSリンク

### 振る舞い

- 公開APIからデータを取得して表示する
- 経歴・スキル・SNSリンクを管理画面で指定した順序で表示する
- データが未登録の項目 (経歴なし、お知らせなし) でもレイアウトが崩れない
- 取得中はローディング、失敗時はエラーを表示する
- 外部リンクを新しいタブで開く場合、`rel` に `noopener` を指定する
- レスポンシブ対応

## 代替案

- **トップページを about ページへのリダイレクトにする** — 実装は減るが、最新記事やお知らせの導線を置く場所がなくなる。不採用。

## 受入条件

- [ ] 未ログインでトップページと about ページを閲覧できる
- [ ] about ページにプロフィール、経歴、スキル、SNSリンクが表示される
- [ ] 経歴・スキル・SNSリンクが管理画面で指定した順序で表示される
- [ ] トップページから趣味記事一覧と技術記事一覧へ遷移できる
- [ ] トップページに最新記事が表示され、記事詳細へ遷移できる
- [ ] 経歴やお知らせが 0 件でもレイアウトが崩れない
- [ ] API 取得失敗時にエラー表示が出て、画面が白紙にならない
- [ ] モバイル幅で崩れずに表示される
- [ ] 外部リンクに `rel="noopener"` が設定されている

## 対象外

- SEO のメタ情報・構造化データ — 別Issue
- i18n による日英切り替え — 別Issue
- 広告表示 — 別Issue

- **H-4** — `GitHub  ↗     X  ↗` (`#2:70`) が 1 テキストノードだが 2 つのリンクにする必要がある。カードの日付 `2026.08.30   →` (`#2:31`) も日付と遷移アフォーダンスが 1 ノードに混在している
- **H-6** — スキルがカテゴリ・習熟度の無いタグの羅列、経歴が 1 文字列。データモデルと突き合わせる
