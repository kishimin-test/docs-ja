# mojica MVP UI設計書

## 1. 概要

mojicaのMVPでは、文字アート画像を生成するためのWeb UIを提供する。

ユーザーは1画面上で必要な情報を入力し、画像の種類を選択して画像を生成できる。

生成された画像はプレビューを表示せず、自動的にダウンロードする。

UIはレスポンシブ対応とし、PC・タブレット・スマートフォンから利用できるようにする。

---

# 2. 画面一覧

MVPでは画像生成画面のみを提供する。

| 画面         | 概要                                       |
| ------------ | ------------------------------------------ |
| 画像生成画面 | 文字・色・画像種類を指定して画像を生成する |

---

# 3. ヘッダー

画面上部にヘッダーを配置する。

ヘッダー左側にmojicaのロゴ画像を配置する。

ヘッダー右側には言語切り替えUIを配置する。

対応言語：

- 日本語
- English

選択された言語に応じて、UI表示とmojica APIへの `Accept-Language` を切り替える。

日本語：

```http
Accept-Language: ja
```

英語：

```http
Accept-Language: en
```

---

# 4. 入力項目

## 描画する文字列

文字アートとして描画する文字列を入力する。

例：

```text
KA
```

入力形式：

`text`

制約：

- 必須
- 1文字以上
- 64文字以下
- 空白文字のみの入力は禁止
- 制御文字は禁止

---

## 描画に使う文字

描画する文字列を構成するために使用する文字を入力する。

例：

```text
🌻
```

入力形式：

`text`

制約：

- 必須
- 1文字以上
- 128文字以下
- 制御文字は禁止
- 空白文字のみの入力は許可する

---

## 描画文字色

描画に使用する文字の色を指定する。

カラーピッカーを使用する。

フロントエンドではHEX形式で値を保持する。

例：

```text
#FFD400
```

mojica APIへHEX形式で送信する。

---

## 敷き詰める文字

描画文字の周囲に敷き詰める文字を入力する。

例：

```text
☀
```

入力形式：

`text`

制約：

- 必須
- 1文字以上
- 128文字以下
- 制御文字は禁止
- 空白文字のみの入力は許可する

ただし、「描画に使う文字」と「敷き詰める文字」の両方を空白文字のみにはできない。

---

## 敷き詰める文字色

敷き詰める文字の色を指定する。

カラーピッカーを使用する。

フロントエンドではHEX形式で値を保持する。

例：

```text
#FF69B4
```

mojica APIへHEX形式で送信する。

---

# 5. 画像種類

画像の種類はセレクトボックスで選択する。

選択肢は以下とする。

| 表示          | APIの値        |
| ------------- | -------------- |
| 標準画像      | `standard`     |
| X背景画像     | `x-background` |
| Xアイコン画像 | `x-icon`       |

初期値は `standard` とする。

---

# 6. 画像生成ボタン

入力フォームの下部中央に、大きな画像生成ボタンを配置する。

ボタンの表示：

```text
画像を生成する
```

ボタン押下時に `POST /images` を実行する。

---

# 7. 画像生成フロー

ユーザーは以下の順序で画像を生成する。

1. 描画する文字列を入力する
2. 描画に使う文字を入力する
3. 描画文字色を選択する
4. 敷き詰める文字を入力する
5. 敷き詰める文字色を選択する
6. 画像種類を選択する
7. 「画像を生成する」を押す
8. `POST /images` を実行する
9. PNG画像を取得する
10. 自動でダウンロードする

画像生成後のプレビューはMVPでは提供しない。

---

# 8. 生成中

画像生成APIへのリクエスト中は、画像生成ボタンを無効化する。

表示を以下に変更する。

```text
生成中...
```

生成中の多重リクエストを防止する。

処理完了またはエラー発生後、ボタンを再度有効化する。

---

# 9. ダウンロード

画像生成に成功した場合、取得したPNG画像を自動的にダウンロードする。

ユーザーによる追加操作は不要とする。

MVPでは以下を提供しない。

- 画像プレビュー
- 手動ダウンロードボタン
- 生成履歴
- 画像のサーバー保存

---

# 10. バリデーション

フロントエンドでは、APIリクエスト前にバリデーションを行う。

## 描画する文字列

以下の場合にエラーとする。

- 未入力
- 64文字を超える
- 空白文字のみ
- 制御文字を含む

日本語メッセージ例：

```text
描画する文字列を入力してください。
```

```text
描画する文字列は64文字以内で入力してください。
```

```text
描画する文字列には表示可能な文字を含めてください。
```

---

## 描画に使う文字

以下の場合にエラーとする。

- 未入力
- 128文字を超える
- 制御文字を含む

日本語メッセージ例：

```text
描画に使う文字を入力してください。
```

```text
描画に使う文字は128文字以内で入力してください。
```

---

## 敷き詰める文字

以下の場合にエラーとする。

- 未入力
- 128文字を超える
- 制御文字を含む

日本語メッセージ例：

```text
敷き詰める文字を入力してください。
```

```text
敷き詰める文字は128文字以内で入力してください。
```

---

## 文字の組み合わせ

「描画に使う文字」と「敷き詰める文字」の両方が空白文字のみの場合はエラーとする。

日本語メッセージ例：

```text
描画に使う文字または敷き詰める文字のどちらかに、表示可能な文字を入力してください。
```

---

## API側のバリデーションエラー

APIから `422 Unprocessable Entity` が返却された場合は、`errors[].field` を利用して対応する入力項目付近にエラーを表示する。

フロントエンドのバリデーションを通過した場合でも、API側のバリデーションを最終的な正とする。

---

# 11. APIエラー表示

フィールドに紐づかないエラーは、フォーム全体で確認できる位置に表示する。

| ステータス | 表示内容               |
| ---------- | ---------------------- |
| 400        | リクエストエラー       |
| 429        | リクエスト回数超過     |
| 500        | サーバーエラー         |
| 502        | 画像生成サービスエラー |
| 504        | タイムアウト           |

APIから返却されたローカライズ済みの `message` をユーザーへ表示する。

内部エラー情報は表示しない。

---

# 12. i18n

UIは日本語と英語の切り替えに対応する。

言語切り替えUIはヘッダー右側に配置する。

切り替え対象には以下を含む。

- 入力項目のラベル
- ボタン
- セレクトボックスの表示名
- フロントエンドのバリデーションメッセージ
- APIエラーメッセージ
- 生成中などの状態表示

日本語選択時は、

```http
Accept-Language: ja
```

英語選択時は、

```http
Accept-Language: en
```

をmojica APIへ送信する。

---

# 13. レスポンシブ対応

PC・タブレット・スマートフォンに対応する。

フォームは基本的に1カラムで構成する。

PCではフォームの最大幅を設定して中央に配置する。

スマートフォンでは利用可能な画面幅に合わせてフォームを広げる。

横スクロールが発生しないことを基本とする。

ヘッダーでは、ロゴ画像と言語切り替えUIが小さい画面でも適切に表示・操作できるようにする。

---

# 14. アクセシビリティ

フォームの各入力項目には対応するラベルを設定する。

キーボードのみでも以下の操作を行えるようにする。

- 入力
- カラー選択
- 画像種類の選択
- 言語切り替え
- 画像生成

エラー表示は色だけに依存せず、テキストでも内容を伝える。

画像生成中はボタンの表示と状態を変更し、処理中であることをユーザーへ伝える。

入力エラーがある場合は、該当フィールドとエラーメッセージをアクセシブルに関連付ける。

ロゴ画像には適切な代替テキストを設定する。

---

# 15. フッター

画面下部にフッターを配置する。

表示内容は以下とする。

```text
© kishimin 2026
```

---

# 16. MVP対象外

以下はMVPでは実装しない。

- 画像プレビュー
- 任意の画像サイズ指定
- 生成履歴
- ログイン
- ユーザー情報の保存
- SNSへの直接共有
- 生成画像のサーバー保存
- 画像から文字を敷き詰める機能

---

# 17. MVPのUIゴール

ユーザーが1画面上で、

「文字を入力する → 色を選ぶ → 画像種類を選ぶ → 画像を生成する」

という最小限の操作だけで文字アート画像を生成し、PNG画像を取得できるUIを提供する。
